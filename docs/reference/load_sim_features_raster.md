# Example feature raster

Load the example feature raster shipped with the package. This access is
retained for compatibility; use
[`load_ecosystem_services()`](https://josesalgr.github.io/multiscape/reference/load_ecosystem_services.md)
to load its matching planning units and raster together.

## Usage

``` r
load_sim_features_raster()
```

## Value

A
[`terra::SpatRaster`](https://rspatial.github.io/terra/reference/SpatRaster-class.html).
