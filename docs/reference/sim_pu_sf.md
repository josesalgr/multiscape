# Simulated planning units

Historical ecosystem-services planning units: 30,496 spatial cells.
These are distinct from `sim_pu`. Prefer
[`load_ecosystem_services()`](https://josesalgr.github.io/multiscape/reference/load_ecosystem_services.md)
to load the matching planning units and feature raster.

## Usage

``` r
data(sim_pu_sf)
```

## Format

An object of class `sf`.
